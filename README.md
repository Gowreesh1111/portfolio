## ✨ About the Project

This is a responsive, single-page portfolio website for **Gowreesh G**, a final-year B.Tech Information Technology student focused on software engineering, cloud technologies, data analytics, and web development.

The site combines a clean professional layout with animated visual details, interactive theme switching, and mobile-friendly navigation. It is built with **HTML5, CSS3, and vanilla JavaScript**—no framework or build process is required.

## 🚀 Features

- **Animated loading screen** with a progress bar and percentage indicator.
- **Animated gradient background** with softly drifting color orbs and a dotted texture.
- **Light and dark themes** with the selected theme saved in browser storage when available.
- **Responsive navigation** with a mobile menu for smaller screens.
- **Smooth section scrolling** and active navigation highlighting.
- **Scroll-reveal animations** for portfolio sections and cards.
- **Animated hero section** with staggered text entrance and a floating profile image.
- **Project and skill cards** with subtle hover effects.
- **Responsive layout** for desktop, tablet, and mobile screens.
- **Reduced-motion support** for visitors who prefer fewer animations.
- **Accessibility basics** including semantic sections, button labels, image alternative text, and visible keyboard focus.
- **Direct contact links** for email, phone, LinkedIn, GitHub, and LeetCode.

## 📁 Project Structure

```text
portfolio/
├── index.html       # Main portfolio page (rename the supplied HTML file)
├── profile.jpg      # Optional profile photo used by the page
└── README.md        # Project documentation
```

> **Profile photo:** The HTML expects an image named `profile.jpg` in the same folder. Add your photo with that filename, or update the image path in the HTML. A generated placeholder is used if the image fails to load.

## ⚡ Run Locally

### Option 1: Open in a browser

1. Download the portfolio HTML file.
2. Optionally place `profile.jpg` beside it.
3. Rename the HTML file to `index.html` (recommended).
4. Open `index.html` in a modern browser.

### Option 2: Start a local server

If Python 3 is installed, run this command from the project folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

No package installation or compilation is needed.

## 🎨 Customization

- **Content:** Edit the text inside the relevant HTML sections.
- **Colors:** Change the CSS variables in `:root` and `:root[data-theme="light"]`.
- **Fonts:** Update the Google Fonts import and `--fh` / `--fb` variables.
- **Profile photo:** Replace `profile.jpg` or update the image `src`.
- **Projects:** Add or edit project cards in the Projects section.
- **Contact information:** Update the email, telephone, and profile URLs before publishing.
- **Animation:** Adjust CSS keyframes and JavaScript scroll-reveal behavior. Preserve reduced-motion support.

## 🌐 Deployment

This is a static website and can be hosted using GitHub Pages, Netlify, or Vercel.

### GitHub Pages

1. Rename the main HTML file to `index.html`.
2. Add `index.html`, `profile.jpg` (if used), and `README.md` to your repository.
3. Commit and push the files to GitHub.
4. Open your repository's **Settings → Pages**.
5. Select the branch and folder to publish.
6. Visit the generated website URL and test the theme, navigation, image, and external links.

## ♿ Accessibility and Browser Support

The portfolio uses modern browser features and is intended for current versions of Chrome, Edge, Firefox, and Safari. It includes visible keyboard focus, button labels, semantic sections, image alternative text, and reduced-motion styling. Keyboard-only and screen-reader testing is recommended before production use.
